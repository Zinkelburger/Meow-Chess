## Design Specificity Verdict
Generic Material admin frame (left nav, top tabs, H1 + instruction sentence, uppercase headers, outlined button rows) around one genuinely TD-native surface (paper-sheet score boxes) and some TD-literate details (W4/D3 cells, board ranges, text section status, rule 5C sentence). Rounds lacks the docs' own round/clock line; round is a 14px dropdown, board numbers the faintest text.
Detector: exit 0 / 0 findings is vacuous (directory scans skip .dart; only web patterns). Deterministic scans corroborate A (15 modal call sites, double-tap-only InkWells, 11px History text, success through showFailure) and add: outline borders 1.9-2.5:1 light (below 3:1), selection tints 1.12-1.27:1; w500 (theme.dart:35, all buttons/chips) and w700 requested but only Inter Regular/SemiBold shipped; 75/263 spacing literals off the 4/8/12/16/24 scale.

## Priority Issues
1. [P1] Rounds makes wrong-round entry easy: 14px round dropdown, faint board numbers, persisted past-round selection (results_view.dart:73-79, 93-95) accepts entry with no banner, no clock/posted time, unfinished = blank. Fix: 24-28px round/time header, 18-20px bold board numbers, read-only past rounds behind "Correcting round N" banner, reset on post, bye line first. Commands: typeset + clarify.
2. [P1] Post→print loop mislabeled and silent: "Pair next round" posts, stays primary at event end ("Nothing to pair. Create a section…"), warnings in 12s snackbar, repeated Swiss caveat, no Print on Rounds. Fix: "Post round 2 · 5 sections", persistent posted strip with Print/Start/Undo, disabled-with-reason, event-complete state. Commands: clarify → harden.
3. [P1] Modals drive core workflows against the binding no-pop-up rule: 15 call sites incl. Make quads, Edit pairings (CSV of section-local numbers), Combine (2 modals), Find player, PDF preview (1000x760 > 720 window), History confirm; dead WorkspaceActions.settings(). Fix: docked Make quads, direct-manipulation swap, side-panel forms, docked preview. Commands: shape → distill.
4. [P1] No door phase: no check-in state/view, lookup is hidden Ctrl+L modal, Add player has no section field, no-shows forced through Withdraw. Fix: Check-in view (Ctrl+I), once-at-post absentee resolution, large docked Lookup panel. Commands: shape → layout.
5. [P1] N05 accessibility gaps: PlainCheckbox no focus visual, no focus-ring token, double-click-only details on Rounds, unlabeled score boxes, hover-only info, 11px text, fixed 48px toolbar, sub-3:1 borders, missing font weights, 8s errors. Commands: audit → harden.
Next tier: [P1] Standings "#" shows roster number in standings order (reads as rank), no rank/tie column, prize classes buried in 9-option submenu, section-local vs event numbering; [P2] no Saved/backup trust signals, backups behind rename pencil, theme resets per launch; [P2] density: first board at y≈374, ~77px rows, ~4 boards visible, header repeated per section.
